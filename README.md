# Estudos de Visão Computacional: Framework YOLO

Repositório dedicado ao estudo, experimentação e desenvolvimento de modelos de detecção de objetos utilizando a arquitetura YOLO (You Only Look Once). Os testes iniciais de ambiente, importação e validação de código foram documentados e executados em ambiente de computação interativa.

---

## Ambiente de Experimentação (Notebook)

O pipeline inicial de testes e a validação do ambiente de execução (incluindo a resolução de dependências de pacotes de terceiros e interpretadores Python) foram consolidados no Google Colab.

Você pode acessar o notebook interativo com o código completo através do link abaixo:

🔗 [Estudo Inicial sobre YOLO no Google Colab](https://colab.research.google.com/drive/152S9LTM5L5XsbjmoRuWdXtWpGr0c2pAK?usp=sharing)

---

## Conteúdo do Estudo

O arquivo original em formato Jupyter Notebook (`.ipynb`) cobre os seguintes marcos de aprendizado:

- **Configuração do Core de IA:** Resolução de conflitos de escopo do instalador de pacotes (`pip`) no ambiente virtual.
- **Validação de Runtime:** Testes de importação do pacote de visão computacional local.
- **Arquitetura Base:** Estruturação dos scripts que servem de fundação para os testes em tempo real com arquivos de mídia externos.
